Журналы и отдельные отчёты XCTest доступны в [запуске WakeGuard iOS](https://github.com/dimakovery-art/WakeGuard/actions/runs/42623727726).

## Что проверяет XCTest

После загрузки проекта в GitHub откройте результаты обеих задач **WakeGuard iOS**. Файл тестов — [WakeGuardTests.swift](../Tests/WakeGuardTests.swift).

- Стандартная серия 08:30–09:00, однозначные времена во всех режимах для интервалов от 1 до 1439 минут и изменение количества вручную.
- Переход через полночь, сдвиг дня недели, индивидуальные UUID.
- Разовый план с сохранённой абсолютной датой и выбор следующего полного окна.
- Подтверждение только конкретного подъёма, сохранение других дней и других планов.
- Сохранение местного часа недельного подъёма при весеннем переходе на летнее время.
- Переопределение настроек, совпадение запросов при повторной сверке и пустая очередь отключённого плана.
- Неверный и верный ответы, смена задания и отсутствие подряд повторяющихся примеров.
- Запись и чтение настроек, плана и частично решённого задания. Повреждённый файл вызывает ошибку и сохраняется для диагностики.

## Приёмка на iPhone с iOS 27

Проведите первый прогон днём. Для быстрого сценария назначьте первый сигнал через две минуты, финал ещё через три минуты и два резерва с шагом в минуту. Укажите сборку приложения, версию iOS, модель iPhone, подключённые устройства и фактическое время. Каждый сценарий ниже пока требует проверки.

| Сценарий | Что сделать и зафиксировать |
| --- | --- |
| Разрешение | При первом сохранении запретить доступ. Проверить сообщение, разрешить будильники в настройках iPhone, сохранить план и увидеть ближайший подъём. |
| Блокировка и завершённое приложение | Заблокировать экран до первого сигнала. Второй прогон провести после принудительного закрытия WakeGuard. Отметить показ и звук каждого сигнала. |
| Независимость | Нажать штатный «Стоп» у первого сигнала. Проверить наступление остальных по своим временам. |
| Повтор и пересечения | Отложить обычный сигнал сначала на 5, затем в отдельном прогоне на 7 и 9 минут. Создать пересечение с другим сигналом и с другим планом. Записать порядок системных экранов, работу Live Activity и какие сигналы фактически прозвучали. |
| Звук, Focus и беззвучный режим | Прослушать запись в настройках. Провести отдельные реальные срабатывания с блокировкой, активным Focus и беззвучным режимом. Сверить русскую фразу с оставшимся временем. |
| Математика | Нажать «Решить пример» при заблокированном телефоне. Ввести неверный ответ. Решить один из трёх примеров, набрать часть следующего ответа, свернуть приложение и перезапустить. Проверить восстановление и отмену резервов после последнего ответа. |
| Штатная и сознательная остановка | Остановить финальный сигнал системной кнопкой и дождаться резерва. В другом прогоне завершить подъём без примеров. Убедиться, что на следующий день недельный план активен. |
| Изменение и удаление | Создать два плана. Отредактировать время первого, выключить его и удалить. Проверить отсутствие старых сигналов и срабатывание второго плана. |
| Сбой и восстановление | Во время постановки длинной серии закрыть приложение, открыть вновь, дождаться сверки. Проверить количество реальных срабатываний. При системном лимите уменьшить число резервов и повторить проверку. |
| Полночь, часовой пояс, переход часов | Установить недельный план с первым сигналом накануне, сменить часовой пояс, открыть приложение. Проверить локальные часы основных сигналов и новые абсолютные даты резервов. Для разового проверить сохранение абсолютной даты. Необычные часы при сезонном переводе проверить отдельно. |
| Перезагрузка iPhone | Назначить близкий подъём, перезагрузить телефон. Проверить до и после первой разблокировки, отдельно записать доступность кнопки примера. |
| Отзыв разрешений | Запретить будильники действующему плану, вернуться в приложение, проверить статус. Восстановить разрешение и повторно сверить регистрацию. |
| Apple Watch | Повторить сигнал с сопряжёнными часами. Зафиксировать устройство вывода звука, вид экрана и доступные кнопки. Доступность кнопок может отличаться от iPhone. |
| Длительное отсутствие | Для недельного плана проверить указанную дату окончания резерва. После исчерпания очереди проверить основные недельные сигналы. Вернуться в приложение и проверить пополнение резервов. |
| Доступность | Проверить редактор и примеры в светлой и тёмной теме, с крупным шрифтом и VoiceOver, особенно отдельные кнопки дней недели, переключатель активности и цифровую клавиатуру. |

Системный звук, маршрутизация на часы, одновременные оповещения и поведение после перезагрузки требуют физического устройства даже после успешного XCTest. [Системные представления AlarmKit](https://developer.apple.com/documentation/alarmkit/scheduling-an-alarm-with-alarmkit)
